# Contributing to my-data-portfolio

This repository is an automated data portfolio generated by Hermes Agent.

## How It Works

- **Weekly publisher** (`publish_study.py`) runs every Monday at 08:00 UTC via GitHub Actions
- It generates 3 topics: **Maroc**, **France**, **Hybrid** (FR↔MA trade)
- Each topic gets a study folder in `studies/` and a dashboard in `dashboards/`
- The `pages.yml` workflow deploys everything to GitHub Pages

## Adding a New Study

1. Create a new folder in `studies/{topic}/` with `analysis.py`, `queries.sql`, `README.md`
2. Create a dashboard in `dashboards/wXX/index.html` with Chart.js visualizations
3. Commit and push — Pages will auto-deploy

## File Structure

```
studies/
├── maroc/     ← Moroccan population/demographics studies
├── france/    ← French economic indicators studies
└── hybrid/    ← FR↔MA trade flow studies

dashboards/
├── w28/       ← W28 Hybride dashboard
├── w29/       ← W29 Maroc dashboard
├── w30/       ← W30 Maroc dashboard
├── w31/       ← W31 Maroc dashboard
└── w32/       ← W32 Maroc dashboard
```

## Data Sources

- **Maroc**: Haut-Commissariat au Plan (HCP)
- **France**: INSEE, Eurostat
- **Hybrid**: Eurostat Comext

## Tech Stack

- Static HTML + Chart.js (CDN)
- GitHub Actions for CI/CD
- GitHub Pages for hosting

## Code of Conduct

Be respectful and constructive in all interactions.
